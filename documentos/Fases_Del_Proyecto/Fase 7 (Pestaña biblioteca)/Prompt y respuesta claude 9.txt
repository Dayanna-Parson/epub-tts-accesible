Ajuste al escáner: agrupamiento sugerido por carpeta
Lo que sí se puede generalizar sin asumir tu convención concreta: si una carpeta contiene varios libros (2 o más archivos EPUB/PDF), es una señal razonable —para cualquier usuario, no solo para ti— de que esos libros están agrupados a propósito (una saga, una colección). Si una carpeta solo tiene 1 libro suelto, no se sugiere nada.
Flujo:
1. Durante el escaneo (sección 2.3), el coordinador, además de listar archivos, agrupa las rutas candidatas por su carpeta contenedora inmediata.
2. Al terminar el escaneo, si detectó carpetas con 2+ libros, no crea etiquetas automáticamente en silencio — muestra un diálogo de confirmación (mismo patrón que el bautizo de Grabación): "Se detectaron 3 carpetas con varios libros dentro. ¿Quieres crear una etiqueta con el nombre de cada carpeta para agruparlos?", con una lista editable — cada fila es Nombre de carpeta propuesto → [editable], con checkbox para incluir o excluir cada una.
3. El usuario puede editar el nombre antes de confirmar (por ejemplo, tu carpeta El juego de Ender - Orson Scott Card la editarías a solo Saga de Ender si quisieras), o desmarcarla si no quiere agrupar esa carpeta en concreto.
4. Las carpetas con un único archivo suelto (tu caso de "Autoconclusivos") nunca entran en esta sugerencia — no hay ambigüedad ahí.
5. Esto es una sugerencia de UNA SOLA VEZ al importar una carpeta nueva, no un proceso que se repite cada vez que reescaneas — se controla con una bandera interna simple para no volver a preguntar por carpetas ya evaluadas.
Sobre guiones bajos y nombres de archivo "sucios"
Esto ya lo resuelve el diseño de la sección 2.7 (coherencia título/archivo): si el título extraído de los metadatos internos difiere del nombre de archivo (con guiones bajos, mayúsculas raras, etc.), se marca titulo_revisado = 0 y usas el título de metadatos como valor por defecto — los guiones bajos del nombre de archivo dejan de importar para lo que ve el usuario, porque no se usa el nombre de archivo como título salvo que no haya metadatos disponibles. En ese caso límite (sin metadatos y con guiones bajos), sí conviene limpiar el nombre de archivo como estimación de título: reemplazar _ y - por espacios y recortar espacios sobrantes, antes de mostrarlo como propuesta editable — nunca aplicar mayúsculas automáticas agresivas (podría destrozar acrónimos o nombres propios).
