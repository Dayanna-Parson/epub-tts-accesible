## Bug confirmado: filtro "Solo nuevas voces" siempre vacío

### Causa raíz — `verificador_voces_nuevas.py` línea 116

El fallo es una **inversión de orden en lo que se guarda en `voces_conocidas.json`**. Traza el flujo:

```
_ejecutar():
  1. ids_conocidos = _leer_ids_locales()          → lee voces_disponibles.json ANTES de descargar
                                                    (snapshot "antiguo" correcto)

  2. gestor.actualizar_voces_desde_internet()     → descarga y SOBREESCRIBE voces_disponibles.json
                                                    con la lista NUEVA completa

  3. _guardar_timestamp()

  4. voces_actuales = gestor.obtener_todas_las_voces()  → lee voces_disponibles.json (ya nuevo)

  5. _detectar_nuevas(voces_actuales, ids_conocidos)    → compara correcto ✓
     → el diálogo emergente funciona bien

  6. _guardar_conocidas(voces_actuales)           ← *** AQUÍ ESTÁ EL BUG ***
     → guarda la lista NUEVA en voces_conocidas.json
```

Después de la ejecución:
| Archivo | Contenido |
|---|---|
| `voces_disponibles.json` | Lista nueva (100 + 5 voces nuevas = 105) |
| `voces_conocidas.json` | Lista nueva también (105 IDs) ← mismo contenido |

Cuando `PanelVoces.cargar_datos_y_llenar()` evalúa (línea 776):
```python
v["es_nueva"] = voces_conocidas is not None and v.get("id","") not in voces_conocidas
```
Como **ambos archivos tienen los mismos 105 IDs**, la expresión `not in voces_conocidas` es siempre `False`. El filtro "Solo nuevas" nunca muestra nada.

---

### Corrección quirúrgica propuesta

**Solo dos cambios en `verificador_voces_nuevas.py`**, dentro del bloque `ANCLAJE: VERIFICADOR_VOCES_NUEVAS`:

**Cambio 1** — En `_ejecutar()`, sustituir la línea 116:
```python
# ANTES (bug):
self._guardar_conocidas(voces_actuales)   # guarda la lista NUEVA (= idéntica a voces_disponibles.json)

# DESPUÉS (fix):
self._guardar_conocidas_ids(ids_conocidos)  # guarda los IDs PREVIOS a la descarga
```

**Cambio 2** — Añadir método `_guardar_conocidas_ids()` que acepta el set de IDs viejos directamente:
```python
def _guardar_conocidas_ids(self, ids: set):
    try:
        ruta = ruta_config("voces_conocidas.json")
        os.makedirs(os.path.dirname(ruta), exist_ok=True)
        with open(ruta, "w", encoding="utf-8") as f:
            json.dump(sorted(ids), f, ensure_ascii=False)
    except Exception:
        pass
```

Con este fix, tras cada verificación:
- `voces_disponibles.json` = lista **nueva** (105 voces)
- `voces_conocidas.json` = IDs **anteriores** (100 voces)

Y `PanelVoces` detecta correctamente las 5 nuevas con `not in voces_conocidas`.
