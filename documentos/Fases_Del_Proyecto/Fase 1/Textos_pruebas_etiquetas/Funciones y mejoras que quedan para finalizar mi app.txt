Mejora de Carga (Latencia del foco en Ajustes y Lectura)
Si NVDA tarda un par de segundos en anunciar dónde estás al cambiar de pestaña, suele ser por un bloqueo en el "hilo principal" (Main Thread) de wxPython.
Causa probable: Al seleccionar la pestaña, el código posiblemente esté leyendo archivos JSON pesados (como la lista de voces de Azure/ElevenLabs) o escaneando la carpeta de caché antes de pintar la interfaz.
La solución: Mover esa carga de datos a un "hilo secundario" (threading) o usar wx.CallAfter para que la ventana se dibuje primero y los datos se rellenen un milisegundo después. Así el foco es instantáneo.

Integración de Piper (Voces locales de alta calidad)
Esta es la mejora más potente para el usuario. Piper es un motor de TTS neuronal que suena increíblemente bien y funciona 100% offline.
El reto: No basta con clonar el repo. Piper funciona mediante archivos .onnx (el modelo de voz) y archivos .json (la configuración).
Implementación: Tendríamos que incluir el ejecutable de Piper en tu carpeta de la app, descargar los archivos de voz que quieras y usar la librería subprocess de Python para enviarle el texto y recibir el audio.
Ventaja: Ofrecerás una alternativa gratuita que suena casi como Azure, ideal para cuando no hay internet o se acaba la cuota.
