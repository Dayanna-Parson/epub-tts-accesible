El objetivo principal de esta versión es la reestructuración completa de la interfaz de configuración para blindar la accesibilidad con el lector de pantalla NVDA mediante un modelo HÍBRIDO, además de implementar mejoras de control.

1.
Estructura del Árbol Híbrido (Izquierda):
Reemplaza el control actual de categorías por un wx.TreeCtrl (self.arbol_cat).
El árbol debe inicializarse completamente expandido por defecto invocando arbol.Expand en sus nodos principales para que el usuario ciego conozca la existencia de todas las sub-ramas de inmediato al recibir el foco.

2.
Habitaciones Independientes (Derecha):

3.
Simplicidad y No Duplicidad (Clase Base Genérica):
Para evitar la duplicación de sizers y lógica repetitiva en las listas y filtros de voces, diseña la clase base parametrizada PanelProveedorIA (de la que heredarán Azure, Deepgram, Polly y ElevenLabs).
Esta clase base debe definir una secuencia lineal vertical estricta para el Tabulador (Idioma -> Casilla "Solo favoritas" -> Casilla "Solo nuevas voces" -> Búsqueda de texto -> ListCtrl de voces -> Botonera inferior). Las casillas de favoritos y nuevas actuarán de forma local e independiente por panel para no contaminar la vista de otros proveedores.
Cada panel derivado debe exponer una propiedad @property def ultimo_control(self) para delegar la comprobación del foco en el Tab handler global de ventana_principal.py de forma dinámica.
