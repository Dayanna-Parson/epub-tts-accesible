**Bug corregido — `recursos/` ya no está preservada en el .bat**

Antes `recursos/version.json` nunca se actualizaba, así que el comprobador siempre veía la misma versión local y nunca notificaba futuras actualizaciones. Ahora solo se preservan los datos reales del usuario: `configuraciones/`, `Grabaciones_Epub-TTS/`, `bin/` e `INICIAR_APP.bat`.

---

**`subir_version.py` — el olvido ya no puede ocurrir**

El flujo de publicación ahora es:

```
python subir_version.py minor     # 1.2.0 → 1.3.0 (o patch, major, o 2.0.0)
# edita novedades.txt con los cambios
git push origin main
# crea el release en GitHub y sube el ZIP del portable
```

Lo que hace solo:
1. Actualiza `recursos/version.json` con la versión nueva y la fecha
2. Añade la cabecera `=== v2.0.0 (23/06/2026) ===` a `novedades.txt` si no existe
3. Hace el commit automático con mensaje estándar
4. Muestra los tres pasos siguientes sin hacer el push nunca solo

Para ponerse al día ahora mismo: `python subir_version.py 2.0.0` desde la raíz del proyecto.
