Recomendación adicional:
El método _hablar() crea un engine de pyttsx3 nuevo en cada llamada (init → say → runAndWait → stop). Esto es costoso y puede generar interferencias de audio si se llama rápido seguido (p. ej. mover un nodo varias veces).
Sugerencia: usar un único hilo con una cola (queue.Queue) y una instancia reutilizable del engine:
# Al inicio de __init__:
self._cola_tts = queue.Queue()
threading.Thread(target=self._worker_tts, daemon=True).start()

def _worker_tts(self):
    import pyttsx3
    engine = pyttsx3.init()
    while True:
        texto = self._cola_tts.get()
        if texto is None:
            break
        engine.say(texto)
        engine.runAndWait()

def _hablar(self, texto: str):
    # Vaciar cola antes de encolar el nuevo (evita backlog)
    while not self._cola_tts.empty():
        try: self._cola_tts.get_nowait()
        except: break
    self._cola_tts.put(texto)
