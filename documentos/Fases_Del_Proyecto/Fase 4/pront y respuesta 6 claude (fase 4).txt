# Lógica de División de EPUB en el Código## Detección de Puntos de Corte
Mostrar más
El método `get_split_lines()` identifica dos tipos de puntos de división:1. **Archivos spine**: cada elemento `<itemref>` en el manifiesto genera un punto de corte2. **Anchors del TOC**: cuando una entrada de tabla de contenidos apunta a un identificador dentro de un archivoEl código crea una lista de diccionarios con estructura: `{'href', 'anchor', 'toc', 'id', 'type', 'num', 'sample'}`.## Manejo del TOCEl método `get_toc_map()` procesa el archivo `toc.ncx` y construye un mapeo: `href → [(text, anchor), ...]`. La lógica coloca enlaces sin anchor antes que los que sí tienen, priorizando divisiones a nivel de archivo sobre divisiones internas.El código **no maneja jeraquía visual** del TOC; simplemente extrae todas las entradas planas de `<navPoint>`.## Determinación de Archivos Spine por CapítuloEl método `get_split_files()` implementa lógica de "chunks":- Itera los `split_lines` marcados como incluidos- Agrupa líneas consecutivas del mismo archivo en un chunk único- Si hay archivos excluidos entre líneas incluidas, crea múltiples chunks para ese archivo- Para cada chunk: extrae contenido, aplica splitHtml si hay anchors, reemplaza URLs internas## Generación de Archivos de Salida`write_split_epub()` ejecuta estas operaciones:1. Escribe `mimetype` sin compresión2. Crea `META-INF/container.xml` y `content.opf` con metadatos actualizados3. Genera `toc.ncx` con nuevas entradas de navegación basadas en split_lines incluidas4. Procesa fuentes encriptadas mediante `FontDecrypter`5. Declara sistema de creación Windows en metadatos ZIP para evitar problemas de permisos**Métodos clave**: `get_split_lines`, `get_toc_map`, `get_split_files`, `write_split_epub`, `splitHtml`.
